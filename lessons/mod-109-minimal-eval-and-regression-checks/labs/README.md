# Labs for mod-109-minimal-eval-and-regression-checks (Minimal Evaluation and Regression Checks for LLM Features)

Guided, step-by-step hands-on sessions. Each lab lists duration, prerequisites, numbered steps with commands or code, expected output, and checkpoints. Unlike the open-ended [exercises](../exercises/), labs are tightly scripted — you read a line, run a command, confirm the result, and move on.

Each lab isolates a *single* move from the module so you can see what that move alone earns before the exercises bundle several together. They can be worked in any order, though the technique each one isolates is referenced forward from the matching chapter.

- [lab-01 — Calibrate a Similarity Threshold on a Hand-Written Rewording Set](lab-01-calibrate-a-similarity-threshold.md) *(30–45 min)* — hand-write three reference answers, three rewordings and three wrong-but-plausible answers per reference, embed all 21 strings with one API call under a pinned embedding model, and compute the two cosine distributions. Pick the threshold at the midpoint, record it with the model name in `tolerance` shape, and note which reference's distributions overlap (chapter 2's test for whether similarity is the right scorer at all). Isolates chapter 2's "Choosing the threshold" drill before exercise 03 bundles it with hand-labelled ground truth, a rule-based scorer, and a calibrated judge.
- [lab-02 — Diff a Baseline Run Against a Candidate Run on Canned Manifests](lab-02-diff-canned-run-manifests.md) *(30–45 min)* — drop two pre-written manifest + JSONL pairs into `evals/<feature>/runs/`, build chapter 4's `diff()` function and a tiny `diff.py` CLI, render the three-category PR-comment (newly failing / newly passing / still failing) with the specific failing sub-check per row and the `code_versions` attribution line, and deliberately trigger the `golden_set_sha` refusal to prove the guardrail fires. No live model calls. Isolates chapter 4's diff shape before exercise 04 runs the eval twice on real models and wraps the diff with cost math, the version-pin assertion, and a shipping recommendation.
- [lab-03 — Bisect a Run Archive to Attribute an Old Still-Failing Row](lab-03-bisect-run-archive-for-old-regression.md) *(25–40 min)* — lay down a five-run archive spanning six weeks and write the `when_did_row_start_failing` walk from chapter 4. Attribute `sum-007` (introduced by PR #458) and `sum-012` (introduced by a trunk run with no PR — the ambient-drift case) correctly, and confirm the walk does not misattribute `sum-001` (never flipped). Compose the three annotated lines into chapter 4's still-failing block. Isolates the attribution primitive before exercise 04's stretch asks you to run it on a long-lived still-failing list.
