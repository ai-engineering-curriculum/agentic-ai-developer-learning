# Labs for mod-108-model-selection-cost-and-prompt-caching (Model Selection, Cost, and Prompt Caching)

Guided, step-by-step hands-on sessions. Each lab lists duration, prerequisites, numbered steps with commands or code, expected output, and checkpoints. Unlike the open-ended [exercises](../exercises/), labs are tightly scripted — you read a line, run a command, confirm the result, and move on.

Each lab isolates a *single* move from the module so you can see what that move alone earns before the exercises bundle several together. They can be worked in any order, though the technique each one isolates is referenced forward from the matching chapter.

- [lab-01 — Price One Feature Call From the `usage` Block](lab-01-price-one-call-from-usage.md) *(25–40 min)* — make one real small-tier API call, read `usage`, look up today's `$/MTok input` and `$/MTok output` on the provider's pricing page, and compute the exact dollar cost by hand; then raise `max_tokens` 10× and watch the billed cost stay flat while the worst-case reservation moves 10×. Isolates chapter 2's "Cost from `usage`, not from the pricing page" habit before exercise 01 asks you to project it to 50,000 calls/day and wire the per-request / per-user budget.
- [lab-02 — Dry-Run `is_confident` on Canned Cascade Outputs](lab-02-is-confident-on-canned-outputs.md) *(30–45 min)* — build the structural + explicit-confidence routing function from chapter 4 and point it at ten pre-written `(small_output, frontier_output, truth)` rows chosen to include every failure class: confident+wrong (miscalibration), unconfident+frontier-agrees (over-escalation), and structurally-invalid-label. Prints the escalation rate `p`, cascade accuracy, miscalibration rate, and over-escalation rate on a dataset you can inspect by eye. Isolates chapter 4's "the confidence check is the whole game" claim with zero real-API cost before exercise 04 runs the full 50-example cascade.
- [lab-03 — Walk a Circuit Breaker Through a Scripted Event Timeline](lab-03-walk-a-circuit-breaker.md) *(25–40 min)* — write only the `CircuitBreaker` state machine from chapter 5's "health-check pattern" and drive it with a 14-row event timeline (`success` / `failure` / `check`) so every transition — `closed → open`, `open → probe`, probe failure, probe success — is pointable in the output. No HTTP, no SDK, no fallback path. Isolates the state machine itself before exercise 05 wires it to a fault-injecting proxy, a fallback path, and the four integration scenarios.
